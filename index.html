Tentang Kami

Kami adalah studio foto wisuda di bawah naungan Fatrah Fhotograf, berbasis di Palembang. Setiap sesi kami rancang dengan konsep yang mewah, khas, dan mudah dikenali — jauh dari kesan foto studio pada umumnya.

Bagi kami, hasil jepretan bukan sekadar file foto. Ia adalah bukti emosional dari perjalanan panjang menuju satu titik: hari kelulusanmu. Itu sebabnya setiap frame digarap oleh tim Teamboys dengan standar servis dan kualitas yang konsisten dari konsultasi awal hingga file diterima.

Client's Note

Alur Booking.

  1. Konsultasi. Hubungi admin AESTHETIC untuk diskusi konsep foto, lalu pilih paket dari pricelist.

  2. Jadwal. Tentukan lokasi, hari, tanggal, dan jam pemotretan bersama tim.

  3. Pembayaran. DP minimal 100K di awal, pelunasan dilakukan H-1 sebelum pemotretan.

  4. File Raw. Seluruh file mentah dikirim maksimal H+1 lewat Google Drive, dengan masa akses 1 minggu.

  5. File Edit. Estimasi selesai 7–14 hari kerja, kecuali menggunakan layanan Fast Track.

Ketentuan Pembatalan

DP yang sudah dibayarkan tidak dapat dikembalikan (hangus) jika pembatalan dilakukan sepihak oleh client.

Sesi wajib dimulai tepat waktu — keterlambatan kedatangan akan mengurangi durasi sesi foto yang telah dipesan.
